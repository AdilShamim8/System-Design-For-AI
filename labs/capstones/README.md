# Capstones — Ship Something Real

Three integrative projects, each ending with a deployed artifact and a one-page design doc. Pick **one** (cap1 for RAG roles, cap2 for platform roles, cap3 for agent roles) — depth beats breadth.

| # | Capstone | You ship | Prereq labs | Hours |
|---|---|---|---|---|
| [cap1](./cap1/) | Customer Support AI | RAG + guardrails + eval gates + monitoring, deployed | b1–b5, c2, x1–x2 | 15–25 |
| [cap2](./cap2/) | Multi-Tenant RAG Platform | isolation, quotas, fairness, per-tenant economics | b2–b5, x1–x3, cap1 recommended | 20–30 |
| [cap3](./cap3/) | Build a Coding Agent | sandboxed repair loop + trajectory eval | c1–c5, b7 | 20–30 |

**The gates:** every capstone defines milestone gates and a final "definition of done." The gates are the course — a capstone that skips them is a tutorial with ambition.

**Portfolio note:** the README you write for your capstone repo (numbers, one-pager, attack-to-layer table) is worth more in interviews than any certificate. See [cap1's final gate](./cap1/README.md) for the checklist.
