# The One-Pager Library — Ten Classic Systems

**What this is:** the classics of system design, compressed to one page each — the three-sentence summary, the spine you can draw in 60 seconds, the numbers to carry, the failure modes that get probed, and the AI-era twist that makes the classic current. These ten cover the majority of real-world design prompts; pair them with the [bridge bank](../06-classical-bridge-questions.md) (the same classics, in question form) and the [whiteboard templates](../whiteboard-templates.md).

**How to drill:** one system per day, blank paper, draw the spine from memory, say the three sentences, recite the numbers with provenance. When you can do all ten cold, any classic variant in an interview is a rearrangement of things you've already drawn. The AI-era twist line is the differentiator — deliver it before they ask.
